The official Tiger Studio 2.60.0, with this fork's additions carried over on top of it.

## New from the official 2.60.0

- **Catalogue brands.** The catalogue asks which brands you follow and shows only their products. Change the list any time with the brands button in the toolbar.
- **Sort by series.** Every colour of the same filament sits side by side.
- **Find by colour in your inventory.** The colour button is now in your inventory's search bar (grid, table and storage): the closest spools come first, the others are hidden.
- **Colour search card.** The colour picker shows straight away; explanations moved into ⓘ bubbles; multicolour spools are counted by default.
- **Lighter on the server.** Studio reads and writes much less to the TigerTag servers.
- **Fixes:** no more empty "undefined · 0/NaN" racks in Storage; the maker's logo on every label layout; `.ttag` import in Import mode and the Feitian licence dongle (both reported from this fork); the friend view's header; the Klipper filament mission; the Favorites view flicker.

## Changed in this fork

- **Mouse wheel on the plans.** The official version now does the same as the fork did (wheel scrolls, Ctrl / ⌘ + wheel zooms), so the official code is used.

## Known limitations

- **Windows and Linux only.** There is no macOS build in this release.
- **The Windows installer is not signed.** Windows SmartScreen warns on first launch: *More info* → *Run anyway*.
- **Sign in with your e-mail and password.** Google sign-in needs the TigerTag Project's own OAuth credentials and does not work in this build.
- **Mounting a spool in a printer slot** (AMS, CFS, ACE…) is not working yet.
- Updates come from this fork's releases, not from the official ones.
